# Phase 5: Brand and marketing

Contents: goal · name · message · visual direction · the one channel · launch assets · subagents · challenges · gate

**Goal:** a name the founder can own, a positioning line in plain words, a
visual direction, and the one channel the first 100 users come from.
Branding is rarely the bottleneck; distribution is. Spend accordingly.

## Name

Generate about twenty, shortlist five, run the checks, then ask with the
checks already done so the founder picks between cleared names only.

Checks per name: say it aloud once and spell it; domain or at least a
usable variant; store search for the same or confusable names; social
handle; a quick trademark search in the founder's main market (USPTO, EUIPO
or DPMA search pages). Record the results in `RESEARCH.md`.

## Message

Reuse the positioning statement from phase 3. Produce the three lines every
store and landing page needs: the one-line subtitle, the first-screenshot
headline, the one-paragraph description. Use the founder's writing skill if
one is installed. Benefit first, feature second, in the glossary's words:
never a word the user wouldn't say.

## Visual direction

Offer three directions as moodboard-style previews (type, palette, one
reference app each) and let the founder choose; then hand execution to the
design skills or tools the founder has. For a store app the icon is the
most-seen brand asset and deserves more iterations than the logo; for a web
app the same is true of the first screen of the landing page.

## The one channel

Pick exactly one primary channel for launch and write the 100-user plan for it
in `VENTURE.md`: weekly actions, who does them (the founder), what counts as
working.

| Channel | Fits when | First action |
| --- | --- | --- |
| Store search (ASO) | A store app, and users already search for the job | Keyword list from competitor listings and reviews |
| Direct outreach | The buyer is a business and can be named | A list of 50 named prospects and a three-line message |
| Communities (forums, subreddits, Discords, groups) | The segment gathers somewhere | Join, help for two weeks, then share |
| Content / SEO | The problem is searched on the web | Three articles answering the exact searches |
| Short video / social | The product demos well in 15 seconds | Build in public: one post per working day |
| Launch platforms (Product Hunt and peers) | Early adopters are the segment | Waitlist first, launch when 50 are on it |
| Paid | Unit economics from phase 3 allow it | Last, and only after one organic channel works |

Building in public costs nothing and compounds; it is the default secondary
channel for a solo founder.

## Launch assets list (owned here, used in phase 8)

Store listing text · five screenshots with headlines · icon · landing page
with email capture · privacy policy page · support address · optional press
kit (one paragraph, three images). Start a public beta or waitlist link now so
phase 7 testers come from the real segment.

## Subagents

`name-checker` runs the domain, handle and store checks per name.
`channel-scout` finds where the segment talks about the problem, with links.

## The angel's challenges

- No logo week before five users have used the prototype.
- One channel done daily beats five done when there is time.
- If the founder cannot describe the product in the user's words, the problem
  is in phase 1, not in the copy.
- A name the founder loves but cannot own is a lawsuit with a deadline.

## Gate 5

`Go` when the name is cleared, the three message lines exist, a visual
direction is chosen, and the primary channel has a written 100-user plan.
No `Kill` here; a name that cannot be cleared loops within the phase.
