# Toolbox: suggestions per phase

Contents: how to use this list · per phase · skills that pair with this one

Suggest a tool only when the phase needs it and the founder has nothing in
place. Prefer what the founder already uses and what the session already has
connected. Names here are starting points, not endorsements; check pricing
and availability at the time, since both change.

| Phase | Need | Options |
| --- | --- | --- |
| 2 Validation | Landing page with email capture | Carrd, Framer, a one-file static page on Vercel or Netlify |
| 2 Validation | Interview scheduling and notes | Calendly or Cal.com; notes straight into `RESEARCH.md` |
| 3 Research | Store data and keywords | Store search itself, AppFigures, Sensor Tower free tier, Google Trends |
| 3 Research | Trademark quick check | USPTO TESS, EUIPO eSearch, DPMA register |
| 4 Architecture | Managed backend | CloudKit (Apple only), Supabase, Firebase; a hosted Postgres if a server is unavoidable |
| 4 Architecture | Subscriptions and checkout | RevenueCat over StoreKit and Play Billing; on the web a merchant of record (Paddle, Lemon Squeezy) or Stripe with its tax add-on |
| 4 Architecture | Analytics, crashes | TelemetryDeck or PostHog; Crashlytics or Sentry |
| 5 Brand | Visual direction, icon, screenshots | Figma (its MCP server if connected), the founder's design skills |
| 5 Brand | Copy | The founder's writing skill |
| 6 Prototype | Clickable mock | Figma prototype, or a throwaway SwiftUI or HTML build |
| 6 Prototype | Remote user tests | A screen-shared call; Maze or Lookback if budget allows |
| 7 Build | Beta distribution | TestFlight, Play internal testing, a password-protected web build |
| 7 Build | Engineering loop | The founder's engineering workflow skill |
| 8 Release | Store assets | Store consoles, Fastlane for screenshots and uploads, a privacy-policy generator checked by a human |
| 8 Release | Launch | Product Hunt, relevant communities, the founder's own list |
| 8 Release | Web launch basics | An uptime check, a transactional email service, the host's backup feature |
| 9 Monitoring | Weekly numbers | The store consoles plus the analytics and revenue tools chosen in phase 4 |
| 10 Business | Books and tax | An accountant in the founder's country before the first tax deadline; bookkeeping software they recommend |
| 10 Business | Support | One shared inbox address; a help page before a help desk |
| 10 Business | Selling the product | A marketplace for small software businesses, or a direct note to adjacent products |

## Skills that pair with this one

This skill runs the venture; it leaves craft to the skills the founder
already has. Look at what is installed and hand over by kind:

- A writing or voice skill: anything the founder publishes.
- A design or design-review skill: before user tests and before store
  screenshots.
- An engineering workflow skill (planning, test-driven development,
  debugging): owns the build loop from phase 7 on.
- A marketing or launch skill: the channel work in phases 5 and 8.

When one of them asks for product context, `VENTURE.md` is the answer.
